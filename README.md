# ARAH — 히어로 대작전 (학습 게임)

초등학생이 **수학 사칙연산과 영어 단어 · 철자 · 듣기**를 2D · 3D 액션 게임으로 익히는 학습 게임입니다.
8개 팀 48명의 히어로(거미 · 아머 · 방패 · 번개 · 거인 · 궁수 · 마법 · 표범)를 팀 스타로 하나씩 모으며, 1~6단계로 실력대로 올라갑니다.
틀린 문제는 **복습 노트**에 저장되어 다시 나옵니다.

| 놀이 | 내용 |
|---|---|
| 🎯 드론 잡기 | 내려오는 드론 중 정답 드론을 줄로 맞히기 (조준) |
| 🏙️ 빌딩 스윙 | 정답 빌딩으로 건너가기 — 팀마다 이동 방법이 다름 (선택 + 시간) |
| 🚪 문 통과 | 달리며 정답 문이 있는 줄로 옮기기, 가능하면 Three.js 3D (달리기) |
| 🕸️ 철자 잇기 | 알파벳 블록을 순서대로 끌어와 영어 단어 완성 (순서) |
| 🃏 짝꿍 찾기 | 문제 카드와 답 카드의 짝 찾기 (기억) |
| 👾 보스 배틀 | 정답으로 보스 체력 깎기, 3콤보 크리티컬 (연속 정답) |

배포: Vercel (Root Directory `web`) — [doc/guides/deploy-vercel.md](doc/guides/deploy-vercel.md)

## 빠른 실행

* **가장 간단한 방법:** `web/index.html`을 브라우저로 엽니다 (인터넷 연결 필요: Phaser 라이브러리를 CDN에서 불러옴)
* **로컬 서버로 실행:** [doc/guides/run-local.md](doc/guides/run-local.md) 참고

## 폴더 구조

```
ARAH/
├─ README.md            프로젝트 소개 (이 파일)
├─ doc/                 문서 (기획 · 콘텐츠 · 의사결정 · 표준 · 가이드 · 테스트)
├─ tools/               개발 도구 (발음 파일 생성 등, 배포되지 않음)
└─ web/                 웹 MVP (Vercel 배포 대상)
   ├─ index.html        진입점
   ├─ assets/           CSS · 이미지 · 사운드
   └─ src/
      ├─ core/          공통 유틸 (저장소, 발음, 랜덤 · 곡선)
      ├─ data/          순수 데이터 (히어로 48명 · 팀, 단어 123개, 단계 · 규칙, 발음 목록)
      ├─ questions/     문제 생성기 (수학, 영어, 오답 복습 노트)
      ├─ game/          게임 (공통 기반 장면, modes/ 놀이 6종, views/ 2D·3D 화면, travels 팀별 이동, 캐릭터 그리기)
      └─ ui/            메뉴 · 결과 화면
```

향후 다른 플랫폼(예: `mobile/`, `godot/`)은 `web/`과 같은 단계에 추가합니다.
`data/`와 `questions/`는 엔진과 무관하게 작성되어 있어, 이식할 때 그대로 재사용할 수 있습니다.
