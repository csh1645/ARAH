# ARAH — 멀티버스 거미 히어로 학습 게임

초등학생(2학년 → 3학년)이 **수학 연산과 영어 단어**를 2D · 3D 액션 게임으로 익히는 학습 게임입니다.
8개 팀 25명의 히어로(거미 · 아머 · 방패 · 번개 · 거인 · 궁수 · 마법 · 표범)를 별로 모으며, 각 팀의 "줄"로 문제를 풉니다.

* 🎯 **드론 잡기:** 내려오는 드론 중 정답 드론을 거미줄로 맞히기
* 🏙️ **빌딩 스윙:** 정답이 적힌 빌딩을 골라 거미줄 스윙으로 건너가기
* 🚪 **문 통과:** 달리면서 정답 문(영어는 그림 문)이 있는 줄로 옮겨 통과하기
* 🌆 **3D 문 통과:** 같은 규칙을 Three.js 3D로 — 도시 위 하늘 다리를 달리는 3인칭 시점
* 🕸️ **철자 잇기:** 알파벳 블록을 순서대로 거미줄로 낚아채 영어 단어 완성하기

배포: Vercel (Root Directory `web`) — [doc/guides/deploy-vercel.md](doc/guides/deploy-vercel.md)

## 빠른 실행

* **가장 간단한 방법:** `web/index.html`을 브라우저로 엽니다 (인터넷 연결 필요: Phaser 라이브러리를 CDN에서 불러옴)
* **로컬 서버로 실행:** [doc/guides/run-local.md](doc/guides/run-local.md) 참고

## 폴더 구조

```
ARAH/
├─ README.md            프로젝트 소개 (이 파일)
├─ doc/                 문서 (기획 · 콘텐츠 · 의사결정 · 표준 · 가이드 · 테스트)
├─ tools/               개발 도구 (발음 파일 생성 등, 배포되지 않음)
└─ web/                 웹 MVP (Vercel 배포 대상)
   ├─ index.html        진입점
   ├─ assets/           CSS · 이미지 · 사운드
   └─ src/
      ├─ core/          공통 유틸 (저장소, 음성, 랜덤)
      ├─ data/          순수 데이터 (히어로, 단어, 교육과정 규칙)
      ├─ questions/     문제 생성기 (수학, 영어)
      ├─ game/          게임 (공통 기반 장면, modes/ 규칙, views/ 2D·3D 화면, 캐릭터 그리기)
      └─ ui/            메뉴 · 결과 화면
```

향후 다른 플랫폼(예: `mobile/`, `godot/`)은 `web/`과 같은 단계에 추가합니다.
`data/`와 `questions/`는 엔진과 무관하게 작성되어 있어, 이식할 때 그대로 재사용할 수 있습니다.
