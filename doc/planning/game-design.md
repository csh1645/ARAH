# 게임 설계서 (GDD) — 히어로 대작전

* **상태:** MVP 고도화 중 (배포: https://arah-web-olive.vercel.app/)
* **대상:** 초등 저학년 아이 1명 (2026년 2학년 → 2027년 3학년), 실력에 따라 1~6단계
* **목적:** 학습 (수학 사칙연산, 기초 영어 단어 · 철자 · 듣기)

## 1. 한 줄 콘셉트

> 8팀 48명의 히어로를 모으며, 각 팀의 "줄"과 능력으로 6가지 놀이 속 문제를 푸는 2D · 3D 액션 학습 게임

## 2. 설계 원칙

1. **문제 풀이 = 게임 조작:** 정답을 고르는 행동이 곧 발사 · 이동 · 공격입니다. "문제 풀고 보상으로 게임" 구조를 피합니다
2. **실패해도 배운다:** 틀린 문제는 결과 화면에서 다시 보여 주고 **복습 노트**에 저장해 다시 냅니다
3. **짧은 한 판:** 한 판 10문제, 3~5분
4. **좋아하는 것과 연결:** 스파이더맨 · 어벤저스처럼 여러 히어로를 모으는 재미 (오마주 디자인, [ADR-0002](../decisions/ADR-0002-original-characters.md))
5. **학년이 아니라 단계:** 화면에는 학년을 보여 주지 않습니다. "여기까지만"이라는 한계 없이 실력대로 올라갑니다

## 3. 공통 루프와 놀이 6종

모든 놀이는 같은 규칙(문제 수, 하트, 점수 · 콤보, 스타, 복습 노트)을 공유하고 **보기를 고르는 방식이 서로 다릅니다** (겹치지 않게 설계).

```
문제 → 놀이별 방식으로 선택
  ├─ 정답 → 점수 + 콤보 → 다음 문제
  ├─ 오답 → (놀이별) 하트 -1 또는 별만 제외, 같은 문제 계속
  └─ 놓침 · 시간 초과 → 하트 -1, 정답 알려 주고 다음 문제
끝(문제 다 풂 · 하트 0 · 보스 격파) → 결과 (팀 스타, 합류 히어로, 틀린 문제 → 복습 노트)
```

| 놀이 | 핵심 능력 | 오답 시 하트 | 제한 시간 |
|---|---|---|---|
| 🎯 드론 잡기 | 조준 · 반응 | -1 | 드론이 위험선에 닿기 전 |
| 🏙️ 빌딩 스윙 | 선택 + 시간 | -1 | 있음 |
| 🚪 문 통과 | 달리며 줄 바꾸기 (3D 자동) | -1 | 문이 도착하기 전 |
| 🕸️ 철자 잇기 | 순서 · 철자 | 없음 (별만 제외) | 없음 |
| 🃏 짝꿍 찾기 | 기억 | 없음 (별만 제외) | 없음 (처음에만 잠깐 보여 줌) |
| 👾 보스 배틀 | 연속 정답 · 속도 | 보스 공격 시 -1 | 보스 공격 충전 |

### 3.1 🎯 드론 잡기
* 차원 포털에서 보기가 적힌 드론이 내려오고, 정답 드론을 줄로 맞힙니다. 드론을 직접 누르면 줄이 따라가서(유도) 빗나가지 않습니다

### 3.2 🏙️ 빌딩 스윙 — 팀마다 건너가는 방법이 다름
* 옥상 간판에 보기가 적힌 빌딩 중 정답 빌딩을 고르면 건너갑니다. 오답이면 실패하고 제자리로 떨어지며 그 빌딩은 막힙니다
* **건너가는 방법 (팀별, `game/travels.js`)**

| 팀 | 이동 | 오답 문구 |
|---|---|---|
| 🕸️ 거미 | 거미줄 스윙 (아래로 처지는 곡선, 잔상) | 줄이 끊어졌어요 |
| ⚙️ 아머 | 제트 비행 (발 불꽃, 위로 솟는 곡선) | 추진기가 멈췄어요 |
| 🛡️ 방패 | 방패 공중제비 (한 바퀴 회전, 방패가 곁에서 돎) | 방패가 튕겨 나왔어요 |
| ⚡ 번개 | 번개 비행 (지그재그 번개 자국, 일직선 고속) | 번개가 빗나갔어요 |
| 💪 거인 | 거인 점프 (아주 높이, "쿵!" 착지 · 화면 흔들림) | 점프가 짧았어요 |
| 🎯 궁수 | 화살 줄타기 (화살 줄 → 미끄러짐 → 착지) | 화살이 빠졌어요 |
| 🔮 마법 | 순간이동 (포털로 사라졌다 나타남) | 포털이 닫혔어요 |
| 🐾 표범 | 표범 점프 (낮고 빠른 두 번 도약, 잔상) | 발이 미끄러졌어요 |

### 3.3 🚪 문 통과
* 로블록스의 "맞는 문 고르기"를 참고. 달리는 동안 다가오는 문 중 정답 문이 있는 줄로 옮겨 통과합니다
* 오답 문은 유리처럼 깨지고, 떨어졌다가 줄로 올라와 같은 구간을 다시 달립니다
* **3D / 2D 자동:** WebGL 이 되는 기기는 Three.js 3D(하늘 다리 3인칭), 안 되면 2D ([ADR-0005](../decisions/ADR-0005-threejs-3d.md))
* 영어는 **단어 → 그림 문** (듣기 + 읽기)

### 3.4 🕸️ 철자 잇기 (영어 전용)
* 그림 · 발음으로 단어를 알려 주고, 떠다니는 알파벳 블록을 순서대로 줄로 끌어와 빈칸을 채웁니다. 2번 틀리면 다음 글자를 반짝여 알려 줍니다. PC 는 키보드 입력 가능 (빨리 쳐도 순서대로 처리)

### 3.5 🃏 짝꿍 찾기 (기억)
* 한 화면에 문제 3~4개 → 카드 6~8장 (문제 카드 하늘색, 답 카드 노란색). 처음에 잠깐 보여 준 뒤 뒤집습니다 (1단계 3초 ~ 6단계 1.5초)
* 두 장을 뒤집어 같은 문제의 짝이면 줄로 묶습니다. 짝이 아니면 다시 뒤집히고, 먼저 뒤집은 카드의 문제는 별에서 빠집니다

### 3.6 👾 보스 배틀 (연속 정답)
* 체력 8의 악당 로봇(메가 드론 킹 · 어둠 로봇 · 번개 골렘 중 하나)과 싸웁니다. 정답 버튼 = 공격(-1), **3콤보 이상은 크리티컬(-2)**
* 오답 버튼은 보스가 막고 공격 충전이 빨라집니다. 충전이 가득 차면 보스 공격(하트 -1)
* 보스 체력 0 → 그 자리에서 승리. 문제를 다 쓰면 보스가 도망갑니다

## 5. 히어로 연합 (8팀 × 6명 = 48명)

* **팀마다 기본 히어로 1명은 처음부터** 고를 수 있습니다 (8명)
* **팀 스타:** 판이 끝나면 받은 스타가 "고른 히어로의 팀" 스타로 쌓이고, 그 팀의 다음 히어로가 합류합니다
* **한 번에 한 명씩:** 팀 안 합류 조건 0 · 10 · 25 · 45 · 70 · 100 의 간격이 한 판 최대 스타(13)보다 커서 한 판에 두 명이 동시에 열리지 않습니다
* 메뉴 도감: 팀별 묶음, 팀 스타 개수, "다음 합류: ○○까지 n개 더"

| 팀 | 스타 | 쏘는 줄 | 팀 능력 (버전이 올라갈수록 추가 능력) |
|---|---|---|---|
| 거미 | 🕸️ | 거미줄 | 버전마다 다름 (콤보 · 넓은 판정 · 속도 · 힌트 · 하트 · 느리게) |
| 아머 | ⚙️ | 레이저 줄 | 스캐너: 가짜 보기 표시 |
| 방패 | 🛡️ | 방패 줄 | 하트 +1~2 |
| 번개 | ⚡ | 번개 줄 | 아주 빠름 |
| 거인 | 💪 | 바위 줄 | 넓은 판정 + 시간 여유 |
| 궁수 | 🎯 | 화살 줄 | 콤보 점수 1.4~2배 |
| 마법 | 🔮 | 마법 줄 | 시간을 느리게 |
| 표범 | 🐾 | 발톱 줄 | 빠름 + 하트 |

히어로별 이름 · 능력 · 색은 `web/src/data/heroes.js`가 기준입니다.

### 5.1 팀별 공격 모양 (`game/attacks.js`)

모든 팀이 거미줄처럼 보이지 않도록, 보기를 고를 때 날아가는 것과 맞았을 때 연출이 팀마다 다릅니다. 드론 잡기 · 철자 잇기 · 보스 배틀에 적용합니다.

**근접 팀(거인 · 표범)은 어떤 놀이에서도 쏘지 않습니다.** 히어로가 직접 목표까지 뛰어올라 때리고 착지합니다 (기반 `meleeTo()`, 점프 높이 = `melee.arc`).
드론 잡기에서는 떨어지는 드론을 따라가 아래에서 올려치고 그 아래 땅에 착지하며, 빈 곳을 누르면 그 자리로 달려갑니다.
철자 잇기에서는 블록을 쳐서 빈칸으로 빙글 날려 보냅니다 (줄 없음).

| 팀 | 공격 | 속도 | 맞았을 때 | 특수 동작 |
|---|---|---|---|---|
| 🕸️ 거미 | 거미줄 | 보통 | 고리 · (드론) 거미줄에 감김 | — |
| ⚙️ 아머 | 굵게 빛나는 빔 | 매우 빠름 | 하늘색 섬광 | — |
| 🛡️ 방패 | 빙글빙글 도는 방패 | 빠름 | 불꽃 | **방패가 손으로 돌아옴** |
| ⚡ 번개 | 지그재그 번개 | 매우 빠름 | 화면 번쩍 · 흔들림 | — |
| 💪 거인 | 직접 점프 (쏘지 않음) | 보통 | 화면 흔들림 · 흙먼지 | **모든 놀이: 높이 뛰어 내려찍기** |
| 🎯 궁수 | 깃 달린 화살 | 빠름 | 고리 | — |
| 🔮 마법 | 반짝이가 도는 마법 구슬 | 보통 | 반짝이 폭발 | — |
| 🐾 표범 | 직접 달려들기 (쏘지 않음) | 빠름 | 할퀸 자국 | **모든 놀이: 낮게 달려들어 할퀴기** |

* 철자 잇기의 끌어오기: 줄이 있는 공격(거미줄 · 빔 · 번개)은 그 모양 그대로, 나머지 투사체 팀은 팀 색의 가는 "힘의 줄"로 끌어옵니다
* 빌딩 스윙의 이동(3.2절)은 공격과 별도로 `game/travels.js` 에서 정합니다

## 6. 점수 · 보상 · 복습

* **점수:** 정답 100점 + 콤보 보너스 `(콤보-1) × 20 × 콤보 배율`
* **스타:** 한 번에 맞힌 문제 1개당 1개, 퍼펙트(3문제 이상 전부 한 번에) 보너스 +3
* **저장:** 브라우저(localStorage)에만 — 스타 합계 · 팀 스타 · 열린 히어로 · 마지막 선택 · 복습 노트. 서버 · 개인정보 없음
* **새 히어로 합류 축하:** 판이 끝나 새 히어로가 합류하면 결과 화면 위에 팀 스타 카드가 흔들리며 뜹니다. 아이가 **직접 눌러 뒤집으면** 만세 자세의 히어로 · 이름 · 출신 · 능력이 나오고, 색종이 · 팡파르와 함께 그 히어로의 한마디가 나옵니다 (`ui/app.js` celebrateJoin). 직접 여는 순간을 보상으로 만들어 모으는 재미를 키웁니다

### 6.1 오답 복습 노트 (간격 반복)
* 틀리거나 놓친 문제는 자동으로 복습 노트의 **상자 1**에 들어갑니다 (이미 있으면 상자 1로 되돌림)
* **'📒 오답 복습' 과목:** 복습 노트 문제만 냅니다 (노트 문제 수가 10개 미만이면 그만큼만)
* **일반 판:** 30% 확률로 같은 과목의 복습 문제를 섞어 냅니다 (표시: "📒 복습 문제")
* 복습 문제를 한 번에 맞히면 상자 +1, **상자 3을 넘기면 졸업 🎓** (노트에서 삭제). 낮은 상자일수록 자주 나옵니다
* 철자 잇기 문제와 그 밖의 문제는 따로 관리합니다 (놀이 형식이 달라서)

## 8. 화면 구성

1. **메뉴:** 히어로 도감(팀별) → 놀이 방법 → 과목(📒 오답 복습 포함) → 단계 → 출동
2. **게임:** 상단 HUD(문제, 하트, 진행도, 점수, 콤보) + 놀이별 화면
3. **결과:** 점수, 한 번에 맞힌 수, 받은 팀 스타, 다음 합류까지, 새 히어로, 복습 노트 저장 · 졸업 수, 틀린 문제 (영어 🔊)

## 10. 소리 (효과음 · 배경음)

모든 소리는 `core/sfx.js` 가 Web Audio API 로 **직접 합성**합니다 (음원 파일 없음 → 저작권 · 용량 걱정 없음). 영어 발음은 별도(원어민 파일, ADR-0004).

| 구분 | 소리 |
|---|---|
| 팀별 발사음 | 거미 "슉", 아머 "지잉"(레이저), 방패 "휙-챙", 번개 "콰직", 거인 "쿵", 궁수 "핑"(활시위), 마법 "띠링", 표범 "샥" |
| 상황음 | 정답 딩동, 오답 부-, 하트 잃음, 콤보 팡파르, 유리 깨짐, 보스 피격 · 보스 레이저, 카드 뒤집기, 착지, 순간이동, 승리 · 아쉬움 |
| 배경음 | 일반: 밝은 코드 진행(112bpm) / 보스 배틀: 긴장감 있는 단조(138bpm). 발음을 가리지 않게 작게 |

* 켜기 · 끄기: 메뉴의 "효과음 · 배경음" 버튼(따로), 게임 중 오른쪽 아래 🔊 버튼(한 번에). 설정은 저장됩니다
* 모바일: '출동!'을 누르는 순간 오디오를 열어 이후 소리가 나게 합니다
* 구조: 모드는 `this.sfx(이름)` · `this.shotSfx()` 만 부르고, 소리 모양은 `core/sfx.js` 의 표(SOUNDS · SHOTS · SONGS)에서만 고칩니다

## 9. 동적 연출

공통(`round-scene.js`): 살아 있는 배경(별 · 달빛 · 서치라이트 · 구름 · 별똥별), 정답 불꽃 · 줌 펄스, 콤보 3 · 5 · 7 · 10 배너, 오답 흔들림 · 빨간 번쩍임.

### 9.1 히어로 애니메이션 (자세 프레임)

그림 한 장이면 단조로워서 아이의 흥미가 떨어집니다. `hero-art.js` 의 자세 표(POSES)로 팔 · 다리 각도와 몸 기울기만 바꾼 8장의 프레임을 판마다 그려 두고, 상황에 맞게 바꿔 끼웁니다 (외부 이미지 없음, 48명 모두 자동 지원).

| 상황 | 프레임 | 어디서 |
|---|---|---|
| 서 있기 | idle ↔ breath (숨쉬기, 0.52초 간격) + 둥실둥실 | 모든 놀이 |
| 달리기 | run1 ↔ run2 (팔다리 번갈아, 0.11초) | 문 통과(2D · 3D), 드론 잡기 이동 |
| 쏘기 · 때리기 | attack (팔을 쭉 뻗음, 손 빛 · 주먹 · 발톱 강조) | 정답을 고를 때 |
| 점프 | jump (두 팔 위, 다리 접기) | 빌딩 건너가기, 근접 공격 |
| 아야 | hurt (얼굴 가리며 움찔, 땀방울 · 어지러운 별) | 오답 · 놓침 |
| 만세 | win (V 자세, 반짝이) | 정답, 3D 문 통과 |
| 승리 춤 | win ↔ jump + 깡충깡충 | 판을 이겨서 끝냈을 때 (지면 털썩) |

* 줄 · 공격이 나가는 손 위치는 지금 자세를 따른다 (`A.heroHand(pose)`, 공격 자세면 뻗은 손 끝)
* 3D 문 통과는 같은 프레임을 뒷모습으로 만들어 쓴다

### 9.2 히어로 대사 (말풍선)

히어로가 머리 위 말풍선으로 말합니다 (`data/hero-lines.js`, 기반 `heroSay()`). 캐릭터마다 느낌이 달라야 애착이 생기므로 두 겹으로 둡니다.

* **팀 말투 (TEAM_LINES):** 원조 캐릭터를 떠올리게 하는 말투를 팀마다 다르게 — 거미 = 장난스러움, 아머 = 자신만만한 천재, 방패 = 다정한 리더, 번개 = 옛 왕국 말투(~노라), 거인 = 짧고 힘센 말, 궁수 = 말수 적고 쿨함, 마법 = 신비로움, 표범 = 침착 · 기품
* **히어로 한마디 (HERO_CATCHPHRASES):** 48명 모두 자기만의 한 줄 (출신 · 능력을 담음)
* **원조 공식 대사 · 유행어는 그대로 쓰지 않는다** — 말투만 살린 새 문장 (ADR-0002)

| 언제 | 무엇을 | 빈도 |
|---|---|---|
| 판 시작 | 히어로 한마디 | 항상 |
| 정답 | 팀 정답 대사 (가끔 한마디) | 35% (말이 너무 많으면 문제 읽기를 방해) |
| 콤보 3 · 5 · 7 · 10 | 팀 콤보 대사 | 항상 |
| 오답 · 놓침 | 팀 격려 대사 (탓하지 않고 "다시 해 보자") | 60% |
| 판 끝 | 승리 / 아쉬움 대사 | 항상 |

말풍선은 1.5초 뒤 사라지고, 떠 있는 동안 일반 대사는 겹치지 않게 건너뜁니다. 테두리는 팀 색, 히어로가 점프 · 이동해도 따라다닙니다 (3D 문 통과는 히어로 위치 위).
