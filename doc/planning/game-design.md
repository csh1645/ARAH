# 게임 설계서 (GDD)

* **상태:** MVP 프로토타입
* **대상:** 초등 2학년 (내년 3학년 진급 예정), 1명
* **목적:** 학습 (수학 사칙연산, 기초 영어 단어)

## 1. 한 줄 콘셉트

> 여러 차원에서 온 거미 히어로가 거미줄을 쏴서, 문제의 **정답이 적힌 드론**만 잡아내는 2D 액션 게임

## 2. 설계 원칙

1. **문제 풀이 = 게임 조작:** 정답을 고르는 행동이 곧 거미줄 발사입니다. "문제 풀고 보상으로 게임" 구조를 피합니다
2. **실패해도 배운다:** 틀린 문제는 결과 화면에서 정답과 함께 다시 보여 줍니다
3. **짧은 한 판:** 한 판에 10문제, 3~5분 이내
4. **좋아하는 것과 연결:** 스파이더버스처럼 여러 거미 히어로를 모으는 재미를 동기로 씁니다 (캐릭터는 오리지널, [ADR-0002](../decisions/ADR-0002-original-characters.md) 참고)

## 3. 핵심 루프와 놀이 방법(모드)

모든 모드는 같은 규칙(10문제, 하트, 점수 · 콤보, 별, 복습)을 공유하고, **보기를 고르는 방식만** 다릅니다.

```
문제 표시 → 모드별 방식으로 보기 선택
   ├─ 정답 → 점수 + 콤보 → 다음 문제
   ├─ 오답 → 하트 -1, 같은 문제 계속 (바로 정답을 다시 찾아보게 함)
   └─ 놓침 / 시간 초과 → 하트 -1, 정답 알려 주고 다음 문제
10문제 완료 또는 하트 0 → 결과 화면 (별 획득, 틀린 문제 복습)
```

### 3.1 🎯 드론 잡기

* 차원 포털에서 보기가 적힌 드론 3~4대가 내려옵니다
* **정답 드론을 거미줄로 맞힙니다.** 드론을 직접 누르면 거미줄이 그 드론을 따라가서(유도) 빗나가지 않습니다
* 정답 드론이 위험선(빨간 점선)을 넘으면 놓친 것입니다
* 특징: 조준과 반응 속도를 쓰는 **액션 중심**

### 3.2 🏙️ 빌딩 스윙

* 옥상 간판에 보기가 적힌 빌딩 3~4채가 나타납니다
* **정답 빌딩을 고르면 안테나에 거미줄을 걸고 스윙해서 건너갑니다.** 착지하면 화면이 다음 구간으로 넘어갑니다
* 오답 빌딩을 고르면 거미줄이 끊어져 제자리로 떨어지고, 그 빌딩은 흐려져 다시 고를 수 없습니다
* 문제마다 제한 시간 막대가 있고(1단계 12초, 2단계 10초, 3단계 8초), 시간이 다 되면 정답을 알려 주고 자동으로 건너갑니다
* 특징: 조준 부담이 없어 **생각해서 고르는 데 집중**. 손 조작이 서툰 아이나 어려운 단계에 적합

### 3.3 🚪 문 통과

* 로블록스의 "맞는 문(그림) 고르기" 오비 게임을 참고했습니다
* 히어로가 달리고, 멀리서 보기가 붙은 유리문 3~4개가 다가옵니다 (원근감 연출)
* **문에 닿기 전에 정답 문이 있는 줄로 옮겨 가면 통과합니다.** 다 골랐으면 대시해서 빨리 도착할 수 있습니다
* 오답 문은 깨지고, 히어로는 떨어졌다가 거미줄로 다시 올라와 **같은 구간을 처음부터 다시 달립니다.** 깨진 문은 판자로 막힙니다
* **영어는 "단어 → 그림" 문제:** 단어를 읽어 주고(🔊) 문에는 그림이 붙습니다. 1단계는 한글 뜻 힌트를 함께 보여 줍니다
* 문이 도착하기까지 시간: 1단계 10초, 2단계 9초, 3단계 7초
* 특징: 달리는 속도감 + 듣기 · 읽기 연습

## 4. 조작

| 모드 | PC | 태블릿 · 폰 |
|---|---|---|
| 🎯 드론 잡기 | ← → 또는 A / D 이동, 스페이스(위로 발사) 또는 클릭(누른 방향으로 발사) | 드론을 터치 |
| 🏙️ 빌딩 스윙 | 숫자 1~4(왼쪽부터), 또는 ← → 로 고르고 스페이스 / Enter, 또는 클릭 | 빌딩을 터치 |
| 🚪 문 통과 | ← → 또는 A / D 줄 이동, 스페이스 / ↑ 대시, 또는 문 클릭 | 문을 터치(같은 문을 한 번 더 누르면 대시), 문제 글자를 누르면 발음 다시 듣기 |

## 5. 멀티버스 히어로

별(⭐)을 모으면 다른 차원의 히어로가 합류합니다. 히어로마다 능력이 달라 "누구로 해 볼까?"라는 선택의 재미를 줍니다.
능력은 **두 모드 모두에서 쓸모가 있도록** 짝을 지어 설계합니다.

| 히어로 | 출신 차원 | 🎯 드론 잡기 | 🏙️ 빌딩 스윙 | 🚪 문 통과 | 합류 조건 |
|---|---|---|---|---|---|
| 레드 스파이더 | 빨강 차원 | 콤보 점수 +50% | 콤보 점수 +50% | 콤보 점수 +50% | 처음부터 |
| 스노우 스파이더 | 눈꽃 차원 | 거미줄 판정 범위가 넓음 | 제한 시간 +2초 | 도착 시간 +2초 | ⭐ 10 |
| 섀도 스파이더 | 그림자 차원 | 거미줄 속도 1.7배, 빠른 연사 | 스윙 속도 1.7배 | 줄 이동 속도 1.7배 | ⭐ 25 |
| 탐정 스파이더 | 흑백 차원 | 가짜 드론 하나를 흐리게 표시 | 가짜 빌딩 하나를 흐리게 표시 | 가짜 문 하나를 막아 둠 | ⭐ 45 |
| 피기 스파이더 | 꿀꿀 차원 | 하트 +1 (4개로 시작) | 하트 +1 | 하트 +1 | ⭐ 70 |
| 퓨처 스파이더 | 미래 차원 | 드론이 30% 느리게 내려옴 | 제한 시간 약 1.4배 | 도착 시간 약 1.4배 | ⭐ 100 |

## 6. 점수와 보상

* **점수:** 정답 1개당 100점 + 콤보 보너스 (`(콤보-1) × 20`, 레드 스파이더는 1.5배)
* **별:** 한 번에 맞힌 문제 1개당 ⭐1, 10문제 모두 한 번에 맞히면 보너스 ⭐3
* **저장:** 별, 마지막으로 고른 히어로 · 과목 · 단계를 브라우저(localStorage)에 저장합니다. 서버나 개인정보는 사용하지 않습니다

## 7. 난이도

난이도는 **숫자 범위, 보기 개수, 드론 낙하 속도**로 조절합니다. 상세 범위는 [content/curriculum.md](../content/curriculum.md)를 참고합니다.

| 단계 | 보기 수 | 드론 낙하 속도 | 스윙 제한 시간 | 문 도착 시간 |
|---|---|---|---|---|
| 1단계 | 3개 | 36 px/s | 12초 | 10초 |
| 2단계 | 4개 | 44 px/s | 10초 | 9초 |
| 3단계 | 4개 | 52 px/s | 8초 | 7초 |

수치는 모두 `web/src/data/curriculum.js`의 `A.RULES`에서 조정합니다.

## 8. 화면 구성

1. **메뉴:** 히어로 선택 → 놀이 방법 선택 → 과목 선택 → 단계 선택 → 출동
2. **게임:** 상단 HUD(문제, 하트, 진행도, 점수, 콤보) + 모드별 화면 (드론 잡기: 포털 · 드론 · 하단 히어로 / 빌딩 스윙: 시간 막대 · 빌딩 · 옥상 히어로 / 문 통과: 원근 도로 · 유리문 · 달리는 히어로)
3. **결과:** 점수, 한 번에 맞힌 수, 획득한 별, 새로 합류한 히어로, 틀린 문제 복습 (영어는 🔊 발음 듣기)

## 9. 동적 연출 (집중 유지)

화면이 계속 살아 움직여야 아이의 시선이 게임에 머뭅니다. 다만 **문제 글자를 가리거나 과하게 번쩍이지 않도록** 약하게 씁니다.
공통 연출은 `round-scene.js`에 있어 모든 모드(앞으로 추가될 모드 포함)에 자동으로 적용됩니다.

| 구분 | 연출 |
|---|---|
| 배경 (항상) | 반짝이는 별, 숨쉬는 달빛, 좌우로 움직이는 서치라이트, 흘러가는 구름, 가끔 지나가는 별똥별 |
| 정답 | 알록달록한 불꽃 파티클, 화면 줌 펄스, 콤보 숫자 튀어 오름 |
| 콤보 3 · 5 · 7 · 10 | 화면을 가로지르는 배너 ("🔥 5 콤보! 대단해요!") + 더 큰 불꽃 |
| 오답 | 화면 흔들림, 빨간 번쩍임, 하트 흔들림 |
| 드론 잡기 | 프로펠러 회전, 드론 기울어 흔들림, 발사 반동 |
| 빌딩 스윙 | 스윙할 때 히어로 잔상 |
| 문 통과 | 흐르는 도로 점선, 달리는 들썩임, 대시 때 속도선 · 잔상, 통과 때 흰 번쩍임, 깨진 유리 파편 |
