### 플레이 테스트에서 확인할 것

* 혼자서 메뉴를 고르고 시작할 수 있는가
* 드론 속도와 보기 수가 적절한가 (너무 어렵거나 지루하지 않은가)
* 어떤 히어로를 고르는가, 별을 모으려고 다시 하는가
* 자주 틀리는 문제 유형은 무엇인가

## Phase 2 — 다듬기 (MVP 검증 후)

* 실제 폰 · 태블릿에서 글자 크기와 터치 조작감 확인 → 필요하면 폰 전용 큰 글씨 설정
* 그래픽 · 효과음 · 배경음 추가
* 3D 확장 검토: 다른 모드의 3D 뷰, 히어로 3D 모델(glTF)
* 새 놀이 방법 후보: 거미줄로 정답 블록을 이어 다리 만들기, 보스 드론 연속 문제
* 틀린 문제를 다음 판에 더 자주 출제 (오답 복습 모드)
* 학습 기록 화면 (날짜별 정답률)
* 영어 문제 듣기 모드 (발음을 듣고 단어 고르기)
* 보스 드론, 히어로 고유 필살기

## Phase 3 — 플랫폼 결정

MVP 결과를 바탕으로 결정하고 ADR로 기록합니다.

* 태블릿 위주 → PWA(홈 화면 설치형 웹앱) 또는 Godot 모바일 빌드
* 기능 확장이 크면 → Godot으로 이식 (`web/src/data`, `web/src/questions` 재사용)
* 여러 아이 · 학부모 리포트 필요 → 서버와 계정 도입 검토 (개인정보 보호 설계 필수)
