# 고도화 검토 (2026-10-10)

MVP 배포(https://arah-web-olive.vercel.app/) 이후 고도화할 수 있는 부분을 **학습 · 콘텐츠 · 재미 · 플랫폼 · 기술 품질** 관점에서 정리했습니다.
기술 항목은 코드를 직접 읽고 확인한 결과이며, 위치는 `파일:줄`로 적었습니다(검토 당시 기준).

* **우선순위:** H(먼저) · M(곧) · L(여유 있을 때)
* **노력:** S(반나절 이하) · M(1~3일) · L(그 이상)

## 0. 이미 처리한 것 (이번 검토 중 수정)

| 항목 | 조치 |
|---|---|
| 원어민 발음 | kokoro-js(Kokoro-82M, `af_heart`)로 단어 40개 wav 생성 · 적용 (총 1.28MB) |
| 발음 연속 재생 시 이전 단어를 기기 음성으로 다시 읽어 소리가 겹치는 버그 | 재생 요청 번호 + AbortError 무시 (`core/speech.js`) |
| Three.js 로딩 실패 시 3D 모드가 메뉴에 남고 엉뚱한 안내가 뜸 | 미등록 모드는 메뉴에서 숨김, 안내 문구 분리 (`ui/app.js`) |
| 3D 유리 파편 형상을 충돌마다 새로 만들고 해제하지 않음 (누수) | 형상 1개 공유 + 종료 시 해제 (`views/gate-view-3d.js`) |
| 단어 추가 시 발음을 전부 다시 만들어야 함 | 생성기를 증분 방식으로 (기존 파일 건너뛰기) |

## 1. 학습 효과 — 가장 중요

| M | 적응형 난이도 | 연속 정답 · 오답에 따라 같은 판 안에서 숫자 범위 · 속도를 조금씩 조절 | M |
| M | 3학년 과정 확장 | 시계 읽기, 길이 · 무게 단위, 분수 기초, 곱셈 (두 자리 × 한 자리) 확대 | M |

## 2. 콘텐츠 파이프라인 — 확장의 전제

| 우선 | 항목 | 내용 | 노력 |
|---|---|---|---|
| H | **발음 자동 생성 (GitHub Actions)** | 단어 · 문장을 데이터에 추가해 push 하면, GitHub 서버에서 kokoro-js(Node)가 **새 항목의 발음만** 만들어 자동 커밋 → Vercel 자동 배포. 사람이 할 일은 데이터 추가뿐. 주의: 워크플로 파일을 push 하려면 토큰에 `workflow` 권한이 필요 | M |
| M | 문장 지원 구조 | 발음 목록 키를 "텍스트" 기준으로 일반화하고, 문장 파일 이름은 내용 해시로 자동 결정 (`s_<해시>.wav`) | S |
| M | 콘텐츠를 JSON 으로 분리 | 단어 · 문장 · 문제 유형을 코드가 아닌 데이터 파일로. 나중에 보호자 · 선생님이 직접 추가하기 쉬움 | M |

## 5. 기술 품질 (코드 검토 결과)

### 5.1 버그 · 엣지 케이스
| 우선 | 위치 | 내용 | 노력 |
|---|---|---|---|
| M | `catch-mode.js:112` | 드론 프로펠러 무한 반복 tween 을 드론 삭제 시 명시적으로 정리하지 않음 → `tweens.killTweensOf` 권장 (자동 정리 여부 확인 필요) | S |

| L | `questions/english.js` | 빈칸 철자 문제에 답이 여러 개일 수 있음 (`c_t` → a/u/o 모두 단어) → 실제 단어가 되는 오답 제외 | M |

1. **아이와 실제 플레이 테스트** (실기기: 글자 크기 · 3D 성능 · iOS 소리 확인) — 이후 우선순위를 다시 조정
