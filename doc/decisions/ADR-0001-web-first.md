# ADR-0001: 웹 우선 개발

* **상태:** 채택
* **날짜:** 2026-10-09

## 배경

플랫폼(웹, 모바일 앱, PC, 게임 엔진)을 아직 정하지 않았습니다. 목적은 초등학생 학습용 2D 액션 게임이며, 먼저 재미와 학습 효과를 검증해야 합니다.

## 결정

* MVP는 **웹(HTML5) + Phaser 3**로 만듭니다
* 빌드 도구 없이 `web/index.html`을 바로 열어 실행할 수 있게 합니다 (일반 `<script>` 사용)
* 문제 생성기와 데이터는 게임 엔진과 분리합니다 (`web/src/questions`, `web/src/data`)
* 정식 플랫폼은 MVP 플레이 테스트 결과를 보고 다시 결정합니다

## 결과

* **장점:** PC · 태블릿 · 폰 브라우저에서 바로 실행, 수정 결과를 즉시 확인, 링크로 공유 가능
* **단점:** Phaser를 CDN에서 불러오므로 첫 실행에 인터넷이 필요합니다. 오프라인 실행이 필요해지면 라이브러리를 `web/assets/vendor/`에 내려받아 사용합니다
* 이식할 때는 `questions/`, `data/`의 로직과 데이터를 그대로 옮기고 화면 부분만 다시 만듭니다
