# ADR-0002: 오리지널 거미 히어로 캐릭터 사용

* **상태:** 채택
* **날짜:** 2026-10-09

## 배경

플레이어(아이)가 스파이더맨, 특히 여러 스파이더맨이 함께 나오는 멀티버스 설정을 좋아합니다. 하지만 '스파이더맨'과 관련 캐릭터의 이름, 디자인, 로고는 저작권과 상표권으로 보호됩니다.

## 결정

* **콘셉트(여러 차원의 거미 히어로)는 살리되, 이름과 외형은 직접 만든 오리지널**로 합니다
* 공식 캐릭터 이름, 고유 디자인, 공식 차원 번호(예: Earth-616)는 쓰지 않습니다
* 캐릭터는 코드(Canvas 그리기)로 직접 그려, 외부 이미지 저작권 문제가 없게 합니다

## 결과

* 앞으로 앱스토어 출시나 외부 공개를 하게 되더라도 캐릭터를 바꿀 필요가 없습니다
* 히어로 추가는 `web/src/data/heroes.js`에 데이터 한 줄과 외형 스타일만 추가하면 됩니다
