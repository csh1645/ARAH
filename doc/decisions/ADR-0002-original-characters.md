# ADR-0002: 히어로 캐릭터 디자인 원칙

* **상태:** 개정 (2026-10-10) — 처음 결정(완전 오리지널)에서 **오마주 디자인**으로 변경
* **최초 날짜:** 2026-10-09

## 배경

플레이어(아이)는 스파이더맨, 그리고 어벤저스처럼 여러 히어로가 함께 나오는 설정을 좋아합니다.
처음에는 공식 캐릭터와 거리를 둔 완전 오리지널 디자인으로 시작했지만, 사용자 검토 결과
"거미 팀은 원작 느낌이 나는데 다른 팀은 어벤저스와 거리가 너무 멀다", "흥미를 위해 원조 캐릭터 느낌이 강해야 한다"는 요구가 있었습니다.

## 결정 (개정)

**원조 히어로를 강하게 떠올리게 하는 오마주 디자인**을 쓰되, 아래 선은 지킵니다.

| 쓰는 것 | 쓰지 않는 것 |
|---|---|
| 대표 색 조합, 상징 장비(가슴의 빛나는 원, 줄무늬 둥근 방패, 망치와 망토, 근육 거인, 활, 마법진, 고양이 귀 마스크), 실루엣 | **공식 이름**(아이언맨 · 캡틴 아메리카 등), **로고 · 글자 마크**, 공식 그림 · 이미지 · 영상 · 음원 파일 |
| 코드(Canvas)로 직접 그린 그림 | 외부에서 내려받은 캐릭터 이미지 |
| 오리지널 이름 (레드 아머, 스타 실드, 썬더 나이트 …) | 원작 대사 · 설정 문구 |

* 히어로 구성: 8팀 25명 (거미 · 아머 · 방패 · 번개 · 거인 · 궁수 · 마법 · 표범), 팀마다 여러 "버전"을 모으는 수집형
* 데이터: `web/src/data/heroes.js`, 그림: `web/src/game/hero-art.js`

## 위험과 대응

* **위험:** 공개 주소에서 원작과 닮은 디자인을 쓰면 권리자의 삭제 요청 등 저작권 · 상표권 문제가 생길 수 있습니다 (로블록스의 원작급 캐릭터 게임은 대부분 정식 계약 콘텐츠)
* **대응**
  * 배포 주소는 **가족 범위로만 공유**합니다 (검색 노출 · 홍보 · 수익화 하지 않음)
  * 공식 이름 · 로고는 절대 넣지 않습니다
  * **널리 공개하거나 수익화 · 앱스토어 출시를 하게 되면, 이 ADR 을 다시 열어 디자인을 오리지널로 바꿉니다** (그림은 `hero-art.js` 한 곳에 모여 있어 교체가 쉽습니다)
  * 권리자 요청이 오면 즉시 해당 디자인을 내립니다
