# ADR-0004: 영어 발음 (미국 원어민 기준)

* **상태:** 1단계 채택, 2단계 검토 중
* **날짜:** 2026-10-10

## 배경

영어 발음은 미국 원어민 기준이어야 합니다. 현재는 브라우저 내장 음성 합성(Web Speech API)을 씁니다.
이 기능은 라이브러리 없이 쓸 수 있지만, **실제 소리는 기기에 설치된 음성에 따라 달라집니다.**

테스트 중 확인한 사례: 개발 PC의 내장 브라우저에는 한국어 음성(Microsoft Heami) 하나만 있었습니다.
이 경우 영어 단어를 한국어 음성이 읽어 원어민 발음이 나오지 않습니다.

| 환경 | 기대할 수 있는 미국 영어 음성 |
|---|---|
| Windows + Edge | Microsoft Aria · Jenny 등 Online (Natural) 신경망 음성 (매우 자연스러움) |
| Windows + Chrome | Google US English (자연스러움, 인터넷 필요) |
| iPad · iPhone (Safari) | Samantha 등 (자연스러움) |
| 안드로이드 태블릿 (Chrome) | Google 영어(미국) 음성 |
| Windows에 영어 음성 미설치 · 내장 브라우저 | 영어 음성 없음 → 한국어 음성이 영어를 읽음 |

## 결정

### 1단계 (적용 완료): 가장 좋은 미국 영어 음성 자동 선택
* `web/src/core/speech.js`가 설치된 음성 중 **en-US + Natural/Neural/Online/Google 등 고품질 음성**을 점수로 골라 씁니다
* 라이브러리는 필요 없습니다

### 2단계 (재생 구조 완료, 파일 출처 결정 필요): 단어별 녹음 파일

* **완료:** 파일 우선 재생 + 기기 음성 대체 구조 (`core/speech.js`, `data/audio-manifest.js`)
* **완료:** 모바일 자동재생 제한 대응 ('출동!' 버튼에서 오디오 잠금 해제)
* **완료:** 생성 스크립트 `tools/audio/generate_word_audio.py` (Google Cloud TTS, 키는 환경 변수로만 전달)
* **남은 일:** 파일 출처를 정하고 40개 파일 생성

### 파일 출처 후보 (2026-10-10 조사)

| 후보 | 방식 | 판단 |
|---|---|---|
| **kokoro-js** (Kokoro-82M, Apache 2.0 가중치) | 브라우저에서 모델 실행. 미국 영어 음성 `af_heart`(등급 A), `af_bella`(A-) | **유력.** 계정 · API 키 불필요. 게임 안에서 매번 돌리면 모델(q8 약 86MB)을 받아야 하므로, **개발 도구 페이지에서 한 번만 생성해 wav를 커밋**한다 |
| Piper (WASM) | 브라우저 · 로컬 실행, 음성 다수 | 대안. 공식 JS 라이브러리 현황은 추가 확인 필요 |
| Kitten TTS | 약 24MB 경량 모델 | 용량은 작지만 음질 평가가 가장 낮음 |
| Google Cloud TTS | 클라우드 API (`tools/audio/generate_word_audio.py`) | 품질 좋음. 계정 · API 키 필요 |
| 브라우저 내장 음성 (현재) | 기기별 음성 | 기기마다 소리가 달라 요구사항 불충족 |

참고: kokoro-js README (jsDelivr, v1.2.0), 브라우저 TTS 비교 글(offlinetts.com, 운영사 자체 벤치마크라 참고용)
* 모든 기기에서 **똑같은 원어민 발음**을 보장하려면, 단어마다 미리 만든 음성 파일(mp3)을 `web/assets/audio/words/`에 두고 우선 재생합니다
* 단어가 40개뿐이라 파일 용량이 작고(전체 약 0.5MB 이하 예상), 인터넷 없이도 재생됩니다
* 파일을 만드는 방법(선택 필요)
  1. 클라우드 TTS(Google Cloud Text-to-Speech, Azure Neural TTS 등)의 미국 영어 신경망 음성으로 한 번만 생성 → 계정과 API 키가 필요하고, 해당 서비스의 이용 약관 확인이 필요합니다
  2. 원어민 녹음 직접 사용 → 품질은 가장 좋지만 녹음 수고가 큽니다
* 녹음 파일이 없는 단어는 1단계 방식(TTS)으로 대체합니다

## 결과

* 지금은 기기 설정만으로 개선할 수 있습니다: 아이가 쓸 기기에서 **Edge 또는 Chrome**을 쓰거나, Windows 설정 → 시간 및 언어 → 음성에서 **영어(미국) 음성을 추가**합니다
* 2단계는 아이와 플레이 테스트를 할 때 실제 기기의 발음 품질을 들어 보고 결정합니다
