# ADR-0007: 단계를 1~12(초1 ~ 중3)로 다시 나누고 추천 학년을 보여 준다

* 날짜: 2026-10-17
* 상태: 결정됨 (ADR-0001 이후의 "학년 숨김" 결정을 일부 바꿈)

## 배경

* 예전 1~6단계는 초1 1학기 ~ 초4 수준이었다. 사용자: "중학생 수준까지 했으면 좋겠다, 영어도 단어 수준 이상이 나와야 한다"
* 2026-10-10 에는 "학년으로 나누면 한계가 생긴다"는 이유로 화면에 학년을 숨겼으나, 단계가 12개로 늘면 어디서 시작할지 알기 어렵다 → 사용자: "단계에는 추천 학년 정보가 필요하다"
* 사용자 선택: 단계는 **전체를 다시 나누기**, 수학 · 영어 **한 번에** 진행. 학년이 올라가도 놀이 수는 늘리지 않고 에이전트 판단에 맡김

## 결정

1. **1~12단계 = 초1 · 초2 · 초3 · 초4 · 초5 · 초6 · 중1 · 중1 · 중2 · 중2 · 중3 · 중3.** 버튼에 "추천 ○○"을 작게 표시. 추천일 뿐 잠그지 않는다
2. **예전 저장값은 같은 수준으로 한 번 옮긴다** (`levelScheme` 2, `A.LEGACY_LEVEL_MAP`: 1 · 2 → 1, 3 · 4 → 2, 5 → 3, 6 → 4)
3. **수학:** 같은 연산에서 수의 종류가 넓어진다 (자연수 → 분수 → 소수 → 정수 → 문자식 → 제곱근). 새 과목 **□와 방정식**(□ 넣기 → 혼합 계산 → 비례식 → 일차 · 연립 · 이차방정식). 값 표기 · 계산은 `questions/math-values.js` 로 분리
4. **영어:** 1~4 단어, 5 어구, 6~12 문장 빈칸(학년별 문법). 오답 = 그 문법의 헷갈리는 형태. 데이터 `data/sentences.js`
5. **놀이는 7개 그대로** — 새 놀이를 만들면 규칙을 새로 익혀야 해서 학습 시간이 준다. 대신 놀이가 내용에 맞춰 변한다: 철자 잇기는 5단계부터 **단어 블록 문장 만들기**, 긴 문장 · 식은 문제 칸 글자를 자동으로 줄임(`setPromptText`), 높은 단계는 제한 시간을 늘림
6. 단계별 게임 수치는 모두 `A.RULES` 로 (보스 충전 · 짝꿍 쌍 수 · 미리 보기 시간도 모드 안에서 옮김)

## 결과

* 아이는 실력이 늘어도 같은 게임 안에서 계속 올라갈 수 있다 (초2 → 중3)
* 남은 일: 문장 · 어구의 원어민 발음 파일 (없으면 기기 음성으로 읽어 부자연스러울 수 있음 — 사용자 피드백 2026-10-17)
