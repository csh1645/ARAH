# 디자인 표준 — "히어로 코믹스"

이 게임의 모든 화면(메뉴 · 게임 HUD · 결과 · 3D 세상)과 소리는 이 문서를 따릅니다. 개발 규칙은 [coding-standards.md](coding-standards.md).
목표: **아이가 한눈에 "히어로 만화 속 세상"이라고 느끼게** — 그림 리소스가 화려하지 않아도 굵은 선 · 단색 · 강한 대비로 완성도를 낸다.
결정 배경: [ADR-0009](../decisions/ADR-0009-full-3d.md) (사용자 선택 2026-10-17: 로블록스풍 3D + 히어로 코믹스 패턴, 무료 리소스만)

---

## 1. 원칙

1. **잉크 선이 기본:** 모든 패널 · 버튼 · 캐릭터 · 소품에 어두운 잉크색 테두리 (그라데이션 · 흐린 그림자 대신)
2. **단색 + 망점:** 면은 평평한 단색, 깊이는 "단단한 그림자(어긋난 잉크 판)"와 망점(halftone)으로 표현
3. **살짝 기울기:** 제목 · 출동 버튼 · 팝업은 -3° ~ +3° 기울여 만화 칸의 역동감을 준다 (본문 · 숫자는 기울이지 않음 — 읽기 우선)
4. **글자는 읽기 먼저:** 문제 · 보기 글자는 장식 없이 크게 (초1 아이 기준), 장식 글꼴은 제목 · 효과음 글자에만
5. **한 화면에 강조색 하나:** 행동을 부르는 곳(출동 · 정답)만 노랑, 나머지는 흰 패널

## 2. 디자인 토큰 (값은 `web/src/core/theme.js` 한 곳에만)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `ink` | `#1d1a2b` | 테두리 · 그림자 판 · 본문 글자 |
| `paper` | `#fffaf0` | 패널 바탕 (약간 따뜻한 종이색) |
| `sky` | `#4fb3ff` | 배경 하늘 · 정보 |
| `sun` (강조) | `#ffd23f` | 출동 · 정답 · 선택됨 — **한 화면에 하나** |
| `hero` | `#ef3e36` | 제목 띠 · 위험 · 하트 |
| `pow` | `#ff7a1a` | 콤보 · 효과음 글자 |
| `go` | `#2fbf71` | 성공 · 진행 |
| `night` | `#3a2f8f` | 보조 패널 · 잠긴 카드 |
| `halftone` | `ink` 12% 점, 간격 8px | 배경 · 큰 패널 무늬 |

* **테두리 두께:** 버튼 · 패널 3px, 작은 칩 2px, 3D 외곽선 = 모델 크기의 약 1.5%
* **단단한 그림자:** `x 4px, y 4px` 잉크색 판 (흐림 0). 누르면 그림자 0 + 4px 이동
* **모서리:** 패널 10px, 버튼 12px, 칩 999px(알약). 만화 칸 느낌을 위해 큰 패널은 6px 이하
* **글꼴:** 제목 · 효과음 = `Black Han Sans`, 본문 · 버튼 = `Jua` (둘 다 Google Fonts, OFL 무료)
* **글자 크기:** 문제 46px(HUD, 길면 24px까지 자동 축소), 버튼 22~28px, 본문 16~18px, 최소 13px

## 3. 부품 (컴포넌트)

| 부품 | 모양 | 어디 |
|---|---|---|
| 패널 `.cx-panel` | 종이색 + 3px 잉크 테두리 + 단단한 그림자 | 메뉴 묶음, 결과 표 |
| 출동 버튼 `.cx-go` | 노랑 + 잉크 테두리 + 그림자, -2° 기울기, 크게 | 메뉴 · 결과의 주 행동 (화면당 하나) |
| 보조 버튼 `.cx-btn` | 흰 종이 + 잉크 테두리 | 다시 하기 · 소리 등 |
| 선택 칩 `.cx-chip` | 알약 모양, 선택되면 노랑 바탕 | 과목 · 단계 |
| 놀이 타일 `.cx-tile` | 정사각 패널, 아이콘 크게, 선택되면 노랑 + 살짝 커짐 | 놀이 방법 |
| 히어로 카드 `.cx-card` | 3D 초상화 + 이름 띠, 잠기면 남색 실루엣 | 도감 |
| 말풍선 `.cx-bubble` | 흰 바탕 + 꼬리 + 잉크 테두리 | 히어로 대사 · 안내 |
| 효과음 글자 (POW) | 별 모양 폭발 + 기울어진 굵은 글자 | 정답 · 콤보 (게임 화면) |
| 제목 띠 | 빨강 띠 + 흰 글자 + 잉크 테두리, -3° | 화면 제목 |

게임 화면(Phaser)도 같은 부품을 그린다: 문제 칸 = 패널, 보기 = 흰 패널 + 잉크 테두리, 정답 표시 = POW 폭발.

## 4. 3D 세상

* **재질:** 단계 음영(toon, 3단계) — 부드러운 그라데이션 대신 만화처럼 뚝 끊기는 명암
* **외곽선:** 히어로 · 소품 · 가까운 건물에 잉크색 외곽선 (뒤집힌 껍데기 방식)
* **하늘:** `sky` 단색 + 흰 망점 구름, 해는 노란 원 + 잉크 테두리
* **색:** 건물은 Kenney 원래 색을 쓰되 단계 음영으로 납작하게. 바닥 · 난간은 토큰 색
* **카메라 고정:** 2D 글자(보기)와 3D 물체가 어긋나지 않게 카메라를 움직이지 않는다 (흔들림은 2D 화면 흔들기로)

## 5. 움직임

| 상황 | 움직임 | 시간 |
|---|---|---|
| 등장 | 0.3 → 1 크기, 살짝 튕김 (Back.Out) | 250~350ms |
| 누름 | 그림자 0 + 4px 이동 | 즉시 |
| 정답 | POW 폭발 + 화면 살짝 확대 | 300ms |
| 오답 | 좌우 흔들림 + 빨간 번쩍 (약하게) | 200ms |

* 깜빡임 · 강한 번쩍임은 초당 3번 이하 (빛 민감 아이 배려), 움직임을 줄이는 설정(`prefers-reduced-motion`)이면 튕김 · 흔들림을 끈다

## 6. 소리

* 효과음 · 배경음은 **녹음된 음원 파일**(CC0)을 쓴다 — 즉석 합성음은 대체 수단
* 성격: 만화처럼 짧고 탄력 있게 (뿅 · 퍽 · 짠). 배경음은 밝은 모험풍, 보스는 긴장감
* 음량: 효과음 > 영어 발음 > 배경음 (발음이 묻히지 않게 배경음은 낮게, 발음 재생 중 배경음 자동 줄임)

## 7. 접근성

* 글자와 바탕 대비 4.5:1 이상 (잉크 글자 + 종이 바탕 = 충분)
* 정답 · 오답은 색만이 아니라 글자 · 모양으로도 (POW / 흔들림)
* 터치 영역 44px 이상

## 8. 바꿀 때

1. 토큰을 바꾸려면 `core/theme.js` 만 고친다 (CSS 변수는 실행 시 자동 생성)
2. 새 부품은 이 문서 3절 표에 먼저 추가하고 같은 이름의 CSS 클래스(`cx-` 접두어)로 만든다
3. 화면을 바꾸면 메뉴 · 게임 · 결과를 모두 같은 규칙으로 맞춘다 (한 화면만 다른 스타일 금지)
